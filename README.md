# DSA-Python

Data Structures and Algorithms implementations in Python.

## Structure

- **Algorithms** - Kadane's, DNF, Floyd's cycle, Sliding window
- **Array** - Array operations, 2D arrays, rotation
- **Bit-Manipulation** - Bit tricks, XOR properties
- **Graph** - BFS, DFS, Dijkstra's, Bellman-Ford, Ford-Fulkerson
- **Greedy-Algorithms** - Job scheduling, Huffman coding
- **Hash-map-set** - HashMap, HashSet implementations
- **Linked-Lists** - Singly, Doubly, Circular linked lists
- **Maths** - Math functions, Bit manipulation
- **Patterns** - Prefix sum, Sliding window, Monotonic stack, Matrix traversal
- **Queue** - Queue implementation
- **Recursion** - Factorial, Fibonacci, Backtracking
- **Searching-Algorithms** - Linear search, Binary search
- **Sorting-Algorithms** - Bubble, Insertion, Selection, Merge, Quick sort
- **Stack** - Stack implementation
- **String** - String operations, Regular expressions
- **Time-Space-Complexity** - Complexity notes
- **Trees** - Binary tree, BST, AVL, Segment tree
